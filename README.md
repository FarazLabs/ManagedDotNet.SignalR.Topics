# ManagedDotNet.SignalR.Topics

Topic-based SignalR hubs for ASP.NET Core: one `Handle(topic, payload)` hub method, DI command handlers, and typed outbound messaging.

```bash
dotnet add package ManagedDotNet.SignalR.Topics
```
